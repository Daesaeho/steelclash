# Steel Clash

Chivalry 2-style melee combat for Minecraft 1.21.1 (NeoForge): directional attacks with windup, release and recovery, parries and ripostes, feints, stamina and disarms, and mobs that fight by the same rules. Spartan Weaponry and Spartan Shields are integrated when installed.

Status: early development (M0). See `docs/PLAN.md`.
